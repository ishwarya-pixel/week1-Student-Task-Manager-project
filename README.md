#  Student Task Manager

Student Task Manager is a simple web application made to help students keep track of their daily tasks. It provides an easy way to add tasks, mark them as completed, and remove them when they are no longer needed.

##  Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* View all, pending, or completed tasks
* See the total number of tasks
* Tasks are saved automatically using LocalStorage
* Works on both desktop and mobile devices

##  Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Git & GitHub

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in your browser.
4. Add some tasks and start using the application.

No database or additional software is required. The tasks are stored directly in the browser using LocalStorage.
